# Business Entity Resolution — Amazon ML Challenge 2026

Given business records from three noisy, independent sources with no shared identifiers,
find every Source-2 and Source-3 record that refers to the same real-world business as
each Source-1 record.

**Current result — validation macro F₀.₅, held-out fold, full-pool retrieval:**

| --- | --- | --- | --- |
| 0.9151 | 0.9571 | 0.8904 | **0.9275** |

## Rules this solution is held to

* **No external data, APIs or network lookups.** Only `student_resource/` is read, and
  inference runs with `HF_HUB_OFFLINE=1`.
* **No GPL dependencies.** Romanisation uses `anyascii` (ISC), never `unidecode`.
* **Country is an open set.** The pipeline partitions on the exact country string and
  never hard-codes, filters or one-hot-encodes one. France appears only in the test set
  and needs no code change.
* **No training on test records.** Labels come only from `train_ground_truth.tsv`.
* **Models MIT / Apache-2.0, ≤ 8B parameters**, enforced by an allow-list in
  `src/ber/device.py` that refuses anything else at load time.
