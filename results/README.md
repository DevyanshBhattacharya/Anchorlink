# results/

Small, committed artefacts — the evidence behind every number quoted in the docs.
Everything here is regenerated by `./run_all.sh`; the large outputs it also produces
(`output/*.tsv`, ~900 MB) are deliberately **not** in git.

| file | what it is |
| --- | --- |
| `BENCHMARK.md` | the full benchmark: blocking per country, matching, leave-one-country-out, the decision-layer ablation, score by cluster size, error analysis with worked examples, and the validator's own output |
| `benchmark.json` | the same, machine-readable |
| `phase0_report.json` | the pipeline run itself: blocking metrics, model info, feature importances, calibration, the chosen decision rule, output row counts |
| `phase1_dense_smoke.json` | the Phase-1 dense bi-encoder code-proving run on Apple MPS |
| `validator.txt` | the organisers' `validate_submission.py`, run with `--check-ids` on the full test set |
